# Traduções em português (pt-BR) do WordZ

`locales/pt-br/common.tsv` e `locales/pt-br/wordcraft.tsv` vêm do
[craft-i18n](https://github.com/storytold/craft-i18n), na versão do arquivo `craft-i18n.rev`
(MIT ou Apache-2.0). O `wordcraft.tsv` traz, no fim, as linhas dos textos novos do WordZ.

A compilação procura as traduções nesta ordem:

1. a pasta da variável `CRAFT_I18N_DIR`, se definida (todos os idiomas);
2. uma pasta `craft-i18n` ao lado da pasta do projeto (todos os idiomas);
3. esta pasta (`i18n-local`): só português e inglês.
